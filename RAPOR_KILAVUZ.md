# RAPOR KULLANIM KILAVUZU

Bu repository'de oyununuz için 2 farklı rapor dosyası bulunmaktadır:

## 1. OYUN_RAPORU.md (Detaylı Versiyon)
- **Sayfa Sayısı:** ~8 sayfa
- **İçerik:** Çok detaylı teknik açıklamalar, tüm kod örnekleri
- **Kullanım:** Referans doküman olarak

## 2. GAME_REPORT_GDOCS.md (Google Docs için Optimize)
- **Sayfa Sayısı:** ~5 sayfa
- **İçerik:** Özet ama kapsamlı, proje raporu için ideal
- **Kullanım:** Google Docs'a kopyalamak için **ÖNERİLİR**

## Google Docs'a Aktarma Adımları

### Yöntem 1: Doğrudan Kopyala-Yapıştır
1. `GAME_REPORT_GDOCS.md` dosyasını açın
2. Tüm içeriği kopyalayın (Ctrl+A, Ctrl+C)
3. Google Docs'ta yeni bir doküman oluşturun
4. Yapıştırın (Ctrl+V)
5. Google Docs markdown formatını otomatik olarak düzenler

### Yöntem 2: Markdown'dan Dönüştürme
1. https://docs.google.com adresine gidin
2. Yeni doküman oluşturun
3. File → Import → Upload
4. `GAME_REPORT_GDOCS.md` dosyasını yükleyin
5. Google Docs formatına dönüştürülür

### Yöntem 3: Online Markdown to Google Docs Converter
1. https://word2md.com veya benzer bir servis kullanın
2. `GAME_REPORT_GDOCS.md` içeriğini yapıştırın
3. Google Docs formatında export edin

## Formatlama Önerileri

### Google Docs'ta yapılacak düzenlemeler:
1. **Başlıklar:** 
   - Ana başlıklar (# ile başlayanlar) → Başlık 1
   - Alt başlıklar (## ile başlayanlar) → Başlık 2
   - (### ile başlayanlar) → Başlık 3

2. **Kod Blokları:**
   - Courier New veya Consolas font kullanın
   - Arka plan rengi: Açık gri (#F5F5F5)
   - Kenarlık ekleyin

3. **Sayfa Düzeni:**
   - Kenar boşlukları: Normal (2.54 cm)
   - Satır aralığı: 1.15 veya 1.5
   - Font: Arial veya Times New Roman (12 pt)

4. **Görseller (İsteğe bağlı):**
   - Unity Editor ekran görüntüleri ekleyebilirsiniz
   - Oyunun itch.io'dan ekran görüntüleri
   - Kod yapısının diagram'ları

## PDF'e Dönüştürme

Google Docs'tan PDF:
1. File → Download → PDF Document (.pdf)
2. Ya da File → Print → Save as PDF
