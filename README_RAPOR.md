## 🎯 Hızlı Başlangıç

### Adım 1: Ana Raporu Word'e Aktar
1. `PROJE_RAPORU.md` dosyasını açın
2. İçeriği kopyalayın (Ctrl+A, Ctrl+C)
3. Microsoft Word'de yeni doküman açın
4. Yapıştırın (Ctrl+V)

### Adım 2: Formatlamayı Düzenle
1. Tüm metni seçin (Ctrl+A)
2. Font: Times New Roman
3. Font Size: 12 punto
4. Line Spacing: 1.5

### Adım 3: Kod Ekran Görüntülerini Ekle
1. `KOD_SCREENSHOT_LISTESI.md` dosyasını açın
2. Her şekil için belirtilen dosyayı Visual Studio/VS Code'da açın
3. Belirtilen satırları ekran görüntüsü olarak alın
4. Word'de ilgili yere ekleyin

### Adım 4: Akış Diyagramını Çiz
1. Draw.io veya Lucidchart'ı açın
2. `PROJE_RAPORU.md` dosyasındaki 4.7 bölümündeki akış diyagramı metnini kullanın
3. Flowchart çizin
4. PNG olarak dışa aktarın
5. Word'e ekleyin

### Adım 5: Son Kontroller
1. Tüm şekiller eklendi mi? (8 şekil)
2. Her şekle metin içinde referans verildi mi?
3. Format doğru mu? (Times New Roman 12pt)
4. Sayfa numaraları var mı?

### Adım 6: PDF'e Dönüştür
1. File -> Save As -> PDF
2. Kaydet
